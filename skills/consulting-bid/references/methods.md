# 公开方法论及适用边界

以下是独立编写的应用指引，非任何咨询公司官方 skill 或内部资料。查阅日期：2026-11-06。只选能改变本次方案决策的框架，并说明输入、分析、输出；不堆砌品牌和模型。具体商务条款、数量、阈值、排期均须来自本次项目，不由方法论决定。

|来源|公开观点的简要转述|本 skill 的应用推导|不适用或限制|
|---|---|---|---|
|[McKinsey：The four building blocks of change，2016-04-11](https://www.mckinsey.com/capabilities/people-and-organization/our-insights/the-four-building-blocks--of-change)|变革需考虑理解认同、制度强化、技能发展、领导示范四方面。|涉及落地时检查沟通、制度、能力及领导行为是否有责任人与动作。|不是所有咨询项目都需完整变革项目；不能由此承诺成功率。|
|[Mercer：Job and career architecture](https://www.mercer.com/en-us/solutions/talent-and-rewards/job-architecture/)|岗位架构可关联技能与人才实践。|仅在人力资源项目中，检查岗位族、层级、能力及人才应用的一致性。|不能自行复刻 IPE 评分、专有量表或薪酬数据库；需合法授权。|
|[Accenture：Strategic Change Management](https://www.accenture.com/en/services/talent-organization/change-management)|以业务价值和人员采用为导向设计变革。|在方案中衔接业务目标、采用动作、测量责任与价值跟踪。|这是本仓库的应用推导，不冒称 Accenture 官方交付标准。|

通用咨询实践：问题树用于拆问题；假设用于设计验证而非预设答案；MECE 用于检查重复和遗漏，复杂现实可交叉但需解释；结论先行用于组织表达；方案比较需一致的评价维度。上述不归为某一家独有。

培训可用逆向设计：先定义可观察工作表现，再定义评价证据，最后安排学习活动；区分反应、学习、行为与业务结果，不能用满意度证明业绩改善。这里是通用教学设计实践，不归为上述三家专有。
