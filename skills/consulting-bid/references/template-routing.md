# 技术标、商务标及汇报稿的分流

标书是一项业务技能，可以在同一 skill 中分别生成技术标、商务标或两者。按本次招标文件分册要求选模式，不将每一模式再安装成互相竞争的技能。

|请求|交付范围|参考材料|不应自动附加|
|---|---|---|---|
|技术标|需求响应、方法、分模块任务成果、计划资源、质量风险及要求的知识转移|技术标模板、招标条款、有效能力证据|未被允许出现的价格、商务条件、额外优惠|
|商务标|报价函/响应函、报价表、授权与资格证明、要求的声明|强制格式、已批准报价、有效企业材料|虚构承诺、擅定有效期、复制他项目资质|
|技术+商务|按招标文件分别组装并做跨册检查|共同需求与报价基线|自动把价格重复写入所有册|
|投标讲解PPT|配合正式投标的汇报及答疑材料|已确认标书内容和汇报模板|以讲解稿替代正式投标文件|

资格、人员、业绩在部分模板里可能出现在技术标或商务标，不能按惯例强行换位置；每项以招标文件为准。要求没有提供时只能形成工作草稿和待核清单，不能依据历史标书自造当前评分表。

技术与商务联动核对：项目名/编号、投标主体、服务模块、工作量、周期、人员、交付与费用包含范围。优惠、免费维保、优先资源、翻译及后续支持均是可能形成义务的内容，只按本次授权填写。历史有承诺不代表公司通用服务标准。

招标文件未要求拆册时可合并；拆册情况下共用稳定需求/成果 ID，对外格式分别遵从要求。文件输出通常为可编辑 Word，另按要求导出 PDF；PDF 不取代源文件审查。扫描资格材料原件按要求附上，不重绘签章。
